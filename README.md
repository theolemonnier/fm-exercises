# fm-exercises
exercises from [CS-461](https://edu.epfl.ch/coursebook/en/foundation-models-and-generative-ai-CS-461)

This repo contains exercises from CS-461. Topic covered are the following: 
- Constrastive learning and Scaling laws (exercise_1)
- SimCLR, BYOL, Barlow twins (exercise_2) 
- DDPM, Stable diffusion and Classifier Free Guidance (exercise_4) 
- Build and train a Class-Conditional Autoregressive Transformer (exercise_5) 
- Implementing, Training and Evaluating DinoV2 (exercise_7) 
- Histopathology Foundation Models (exercise_9) 
- In-context learning and quantization (exercise_10)
